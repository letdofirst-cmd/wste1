# EcoPulse

Smart waste management: report waste, follow each fix, earn EcoCredits.

Single-file web app. No server, no npm, no internet needed. Data is saved in the browser (localStorage).

## Run locally
Double-click `index.html` (Chrome / Edge / Firefox).

## Live site (GitHub Pages)
Repo Settings > Pages > Source: `main` branch, `/ (root)`.
